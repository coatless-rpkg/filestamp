# Apply header updates to a single file

Apply header updates to a single file

## Usage

``` r
update_one_file(file, updates, action)
```

## Arguments

- file:

  Character. Path to file.

- updates:

  Named list of updates.

- action:

  Character. Action to perform.

## Value

TRUE invisibly, FALSE if skipped, or a preview object for "dryrun".
