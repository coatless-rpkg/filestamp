# Modify file with header

Modify file with header

## Usage

``` r
modify_file(file, template, language, ...)
```

## Arguments

- file:

  Character. Path to file to modify.

- template:

  stamp_template object. Template to use for stamping.

- language:

  stamp_language object. Detected language for formatting comments.

- ...:

  Additional arguments passed to render_template.

## Value

TRUE invisibly on success.
