# Preview stamp without modifying

Preview stamp without modifying

## Usage

``` r
preview_stamp(file, template, language, ...)
```

## Arguments

- file:

  Character. Path to file to preview.

- template:

  stamp_template object. Template to use for stamping.

- language:

  stamp_language object. Detected language for formatting comments.

- ...:

  Additional arguments passed to render_template.

## Value

stamp_preview object.
